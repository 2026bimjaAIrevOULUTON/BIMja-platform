# Context data

`agra-taj-mahal.osm` is an extract of OpenStreetMap data around the Taj Mahal, Agra (bbox 78.029, 27.163 to 78.056, 27.187). It was taken from the OpenStreetMap API on 22 Nov 2026 and is used by "Build city from OpenStreetMap" so the Taj context builds offline and reproducibly.
