Drawing packs

Each pack adds only the sheets the model can fill: services by discipline, coordinated services with clashes ringed, isometrics, spools, builder's work, plant, containment, single-line diagrams, whitespace, equipment and fire strategy.

Issue

Publishing bumps each sheet's revision (P01… for S codes, C01… once authorised), records it in the register, and downloads one zip. DXF opens in AutoCAD and can be saved as DWG there.
